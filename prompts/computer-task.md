# Computer Use実習：Issueスナップショットを表で整理する

## 使用ファイル

`data/issues_snapshot.csv`

このファイルは教材用の架空データです。ほかのファイルや実業務データとは結合しません。

## AIへの依頼例

```text
ダウンロード済みの issues_snapshot.csv を表計算アプリで開いてください。

1. state が open の行だけに絞る
2. severity が S1 または S2 の行を上に並べる
3. title列だけを比較し、内容が似ている重複候補の行へ薄い黄色を付ける
4. status が needs-info の件数を数える
5. 元データは上書きせず、triage_result.xlsx として保存する
6. 保存したファイルを開き直し、行数と列名を確認する

ファイルのアップロード、メール送信、外部共有はしないでください。
```

## 講師Macでの推奨

NumbersでCSVを開き、フィルター、並べ替え、セル装飾、Excel形式への書き出しを行います。高度なExcel固有機能は使いません。

## 受講Windowsでの代替

- Computer Useが利用可能：端末に既にある表計算アプリで実行
- 表計算アプリがない：Googleスプレッドシートで同じ操作を手動体験
- Computer Useが利用不可：講師デモを観察し、Browser Useの結果表を作る

Googleスプレッドシートを使う場合も、この架空CSV以外はアップロードしません。

## 完了条件

- 元CSVが上書きされていない
- Openだけが表示されている
- S1/S2が上に並んでいる
- title列を根拠に選んだ重複候補の色付けがある
- 保存したファイルを再度開いて確認している
